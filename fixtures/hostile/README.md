# Hostile and damaged PDFs

Generated by `python3 -I fixtures/tools/generate.py` (standard library only, nothing downloaded). The PDFs are not
committed; [manifest.tsv](manifest.tsv) is, and names for each file the limit of
[docs/21](../../docs/21-PARSER-LIMITS.md) it crosses, the code a strict read returns, and what the default recovering
reader must do: `refuse`, `open+report` or `open+remove`. `--check` keeps the manifest, the generator and docs/21 in
step. The reader's tests (stage 1A, `T-1A`) assert each row.

Generated size is about 130 MB, most of it in `many_objects.pdf`, `too_large.pdf` and `string_16mib_plus.pdf`.
