# 21 — Parser and input limits

Every limit the code will hold, its default, its code, and whether a hostile fixture proves it. **PDF limits are built and tested** in `casual-sign-pdf` (stage 1A); the others are proposed. Every PDF limit has a hostile fixture, generated by
`fixtures/tools/generate.py` and listed in `fixtures/hostile/manifest.tsv` with its expected code (`F-005`). Each default becomes a host-overridable value in `casual-sign-pdf::Limits` or the server's
configuration; the defaults are chosen to admit every corpus document with headroom, and are re-measured at the
Phase 1 gate.
