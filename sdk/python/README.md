# openseal (beta)

The OpenSeal API client for Python 3.9+: one method per operation of the OpenSeal API
([api/openapi.yaml](../../api/openapi.yaml)), the OAuth 2.1 helpers, and webhook
signature verification. Standard library only.

```python
from openseal import OpenSeal, verify_webhook

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
env = client.create_envelope(idempotency_key="order-42", body={
    "subject": "NDA", "status": "sent",
    "documents": [{"name": "nda.pdf", "content_base64": content_base64}],
    "recipients": [{"ref": "s", "type": "signer", "name": "Ada", "email": "ada@example.com"}],
    "fields": [{"recipient": "s", "document": 0, "type": "signature", "page": 1, "x": 72, "y": 600, "width": 180, "height": 40}],
})

url, verifier, state = client.authorization_url(client_id, redirect_uri, "envelopes:read")
client.token(client_id=client_id, client_secret=client_secret, grant_type="authorization_code",
             code=code, redirect_uri=redirect_uri, code_verifier=verifier)

event = verify_webhook(os.environ["OPENSEAL_WEBHOOK_SECRET"], request.headers, raw_body)
```

Methods are the API's operationIds in snake case (the camel-case name works too);
refusals raise `OpenSealError` with the stable `code` of
[docs/20](../../docs/20-ERROR-CODE-REGISTRY.md). `openseal/_operations.py` is generated by
`tools/build-sdks.py`; do not edit it. Tests (offline, against
`../contract/recorded.json`): `python3 -I -m unittest discover -s sdk/python/tests -t sdk/python`.
