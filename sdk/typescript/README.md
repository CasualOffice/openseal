# @openseal/sdk (beta)

The OpenSeal API client for JavaScript and TypeScript: one method per operation of the
OpenSeal API ([api/openapi.yaml](../../api/openapi.yaml)), the OAuth 2.1 helpers, and
webhook signature verification. ES module, no dependencies; Node 20+, Deno, Bun and
browsers.

```js
import { OpenSeal, verifyWebhook } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const env = await os.createEnvelope({ idempotencyKey: "order-42", body: {
  subject: "NDA", status: "sent",
  documents: [{ name: "nda.pdf", content_base64 }],
  recipients: [{ ref: "s", type: "signer", name: "Ada", email: "ada@example.com" }],
  fields: [{ recipient: "s", document: 0, type: "signature", page: 1, x: 72, y: 600, width: 180, height: 40 }],
} });

// OAuth: send the member to `url`, keep `verifier` and `state`, then exchange the code.
const { url, verifier, state } = await os.authorizationUrl({ clientId, redirectUri, scope: "envelopes:read" });
await os.token({ clientId, clientSecret, grant_type: "authorization_code", code, redirect_uri: redirectUri, code_verifier: verifier });

// A webhook: the raw body, exactly as received.
const event = await verifyWebhook(process.env.OPENSEAL_WEBHOOK_SECRET, request.headers, rawBody);
```

Method names are the API's operationIds; refusals throw `OpenSealError` with the stable
`code` of [docs/20](../../docs/20-ERROR-CODE-REGISTRY.md). `operations.js` and
`operations.d.ts` are generated by `tools/build-sdks.py`; do not edit them. Tests:
`node --test test/*.test.mjs` (offline, against `../contract/recorded.json`).
