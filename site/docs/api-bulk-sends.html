Bulk send

One template sent to a list of people, one envelope each: check the list, then send it in batches.

Endpoints
  • GET/api/v1/bulk-sends
  • POST/api/v1/bulk-sends
  • GET/api/v1/bulk-sends/{id}
  • POST/api/v1/bulk-sends/{id}/send
  • POST/api/v1/bulk-sends/{id}/cancel

List bulk sends

GET/api/v1/bulk-sends

The caller's bulk sends, newest first, without rows (every member's for an administrator or a member who sees every envelope)

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

    minimum 1 · maximum 100 · Default 50

Returns

Create bulk send

POST/api/v1/bulk-sends

Check a list of recipient sets against a template, and make a bulk send of it

The list is CSV text (a header, then one row per envelope) or JSON rows; its columns are two per template role, in role order: <role>::name and <role>::email, matched ignoring case and surrounding spaces. A header that does not fit the template is 422 (CS-BLK-0004 missing columns at /columns, CS-BLK-0005 an unknown or repeated column at /columns/{i}); no row, more than 1000, or CSV that cannot be read is 422 CS-BLK-0007. Each row is checked: CS-BLK-0001 a missing value, CS-BLK-0002 an email that cannot be one, CS-BLK-0003 a name over 255 characters or with control characters, CS-BLK-0006 more values than columns. A row with a problem is stored failed and never sent. With validate_only nothing is stored: the answer is 200 with each row's check. Send the batch with POST …/send. Also needs envelopes:write and envelopes:send, as POST /envelopes with status: sent does. A line with no value in any cell is skipped.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionbulk.send · OAuth scope bulk:send

Request body

Content type application/json · required

  • template_idstringRequired

    A template of the caller's account with a document and a role

  • namestring

    Defaults to the template's name

    at most 255 characters

  • csvstring

    The list as CSV text; exactly one of csv and rows

  • rowsarray of object

    at most 1000 items

  • validate_onlyboolean

    Default false

Returns

200 validate_only: each row's check; nothing stored with a BulkSendCheck object.

Limits

  • Bulk send list (POST /bulk-sends, UXW-04): rows; values; rows sent per …/send call: 1–1,000 in the 1 MiB body (CSV or JSON); name 1–255 characters without control characters, email 3–320 bytes with one @ and no spaces; 10

Send bulk send rows

POST/api/v1/bulk-sends/{id}/send

Send the next pending rows, at most 10, one envelope each; repeat until none is pending

Each row is made and sent as POST /envelopes makes and sends one, in its own transaction; a row the server refuses is failed with the refusal's code and the others go on. Once no row is pending the bulk send is completed. Only its sender sends it (403 otherwise). Also needs envelopes:write and envelopes:send.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionbulk.send · OAuth scope bulk:send

Path parameters

  • idstringRequired

    One of the caller's own bulk sends

Returns

200 with a BulkSendWithRows object.
