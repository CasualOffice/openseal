Accept invite

POST/api/v1/auth/accept-invite

Spend a user invitation's one-time link and set the password

An unknown, expired, spent or revoked link, or a member disabled meanwhile, is 401 CS-AUTH-0002, all alike. Setting the password ends the member's sessions in every account they belong to. The member then logs in with /auth/login. Rate-limited as login.

AuthNone (public)

Request body

Content type application/json · required

  • tokenstringRequired

    The token from the invitation link

    at most 128 characters

  • passwordstringRequired

    Not on the bundled list of breached passwords, case ignored (422 common_password at /password); setting it emails the user a notice

    at least 12 characters · at most 256 characters

Returns

200 with application/json.

Request password reset

POST/api/v1/auth/password-reset

Ask for a password-reset email

No session. 202 {} for any well-formed address, whether or not it has an account (no enumeration). For a local, enabled user the worker emails a one-time link that expires in an hour; only the SHA-256 of its token is stored. At most one email a minute per user; rate-limited as login, per address and per client.

AuthNone (public)

Request body

Content type application/json · required

  • emailstringRequired

Returns

202 Accepted with a Object object.

AuthNone (public)

Request body

  • passwordstringRequired

Returns

200 with application/json.

Limits

Reauthenticate

POST/api/v1/auth/reauthenticate

Prove the password again before a sensitive action

password, and when the user has a second factor also code (single use), recovery_code (spent), or passkey, an assertion answering a reauthenticate challenge from POST /auth/mfa/passkeys/options. Opens a five-minute window in which the session's sensitive actions are served; outside it they answer 403 CS-AUTH-0013 and the client asks for this and repeats the request. 401 CS-AUTH-0007 for a wrong password, 401 CS-AUTH-0012 for a wrong or reused code, 422 CS-API-0001 (/code) when a factor is needed and none was sent. Rate-limited per user as login is. A staff session only.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session; any signed-in caller

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • passwordstringRequired
  • codestring
  • recovery_codestring
  • passkeyPasskeyAssertion

    A WebAuthn assertion (navigator.credentials.get), each part base64url without padding

    Child attributes of passkey
    • credential_idstringRequired

      rawId

    • client_data_jsonstringRequired
    • authenticator_datastringRequired
    • signaturestringRequired
    • user_handlestring

Returns

200 with application/json.

Verify second factor

POST/api/v1/auth/mfa/verify

Pass the session's second factor

With code, six digits from the user's authenticator (RFC 6238, 30-second steps, one step of drift either way); or with recovery_code, one of the ten codes shown at enrolment, which is spent (case, spaces and dashes do not matter). Each TOTP code is accepted once: a code for a step no later than the last accepted one is refused. 401 CS-AUTH-0012 for a wrong, replayed or spent code. Rate-limited per user as login is. Until a session that owes a factor passes it, every other /api/v1 call but GET /auth/session and POST /auth/logout answers 403 CS-AUTH-0011. With passkey, an assertion answering the session's verify challenge: refused (401 CS-AUTH-0012) for another purpose's, an expired or a spent challenge, another origin or RP id, a credential not the user's, a bad signature, or a signature counter that did not move past the stored one (a cloned authenticator; logged with reason: counter).

Passkey options

purpose is register (navigator.credentials.create), verify (the sign-in step) or reauthenticate (step-up, navigator.credentials.get).
