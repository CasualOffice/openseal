Webhooks

Subscriptions that receive signed event notifications (the Standard Webhooks scheme), their delivery log, test events and redelivery. See Webhooks for verifying them.

Endpoints
  • GET/api/v1/webhooks
  • POST/api/v1/webhooks
  • GET/api/v1/webhooks/{id}
  • PATCH/api/v1/webhooks/{id}
  • DELETE/api/v1/webhooks/{id}
  • GET/api/v1/webhooks/{id}/deliveries
  • POST/api/v1/webhooks/{id}/test
  • POST/api/v1/webhooks/{id}/deliveries/{delivery}/redeliver

Create webhook

POST/api/v1/webhooks

Subscribe (public HTTPS URLs only)

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionwebhooks.manage · OAuth scope webhooks:manage

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • urlstringRequired

    https:// to a public address

  • event_typesarray of stringRequired
  • secret_refsarray of stringRequired

    at least 1 items · at most 4 items

  • envelope_idstring

Returns

201 with a Webhook object.

POST/api/v1/webhooks

curl

curl -X POST https://sign.example.com/api/v1/webhooks \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H 'Idempotency-Key: order-1042' \
  -H "Content-Type: application/json" \
  -d '{
  "url": "https://hooks.example.com/openseal",
  "event_types": [
    "envelope.completed",
    "envelope.declined"
  ],
  "secret_refs": [
    "OPENSEAL_WEBHOOK_SECRET_CRM"
  ]
}'

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const result = await os.createWebhook({
  idempotencyKey: "order-1042",
  body: {
    "url": "https://hooks.example.com/openseal",
    "event_types": [
      "envelope.completed",
      "envelope.declined"
    ],
    "secret_refs": [
      "OPENSEAL_WEBHOOK_SECRET_CRM"
    ]
  },
});

Python

import os

            "envelope.completed",

        "secret_refs": [
            "OPENSEAL_WEBHOOK_SECRET_CRM",

)

Test webhook

POST/api/v1/webhooks/{id}/test

Send a test event through the worker

Records a webhook.test delivery (ids only) and queues it; the worker signs and sends it as any delivery (SEC-W01 at connect time) and records the answer in the delivery log. 202 with the delivery as recorded; a paused or disabled subscription is 409 CS-API-0009.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionwebhooks.manage · OAuth scope webhooks:manage

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Returns

202 Accepted with a Object object.

Redeliver webhook

POST/api/v1/webhooks/{id}/deliveries/{delivery}/redeliver

Deliver one delivery's event again

The same event id and payload, through the worker; the URL is checked again. 202 with the delivery back to pending; a paused or disabled subscription is 409 CS-API-0009.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionwebhooks.manage · OAuth scope webhooks:manage

Path parameters

  • idstringRequired

    Object id (UUIDv7)

  • deliverystringRequired

    Delivery id (UUIDv7)

Returns

202 Accepted with a Object object.

POST/api/v1/webhooks/{id}/deliveries/{delivery}/redeliver

curl

  -H "Authorization: Bearer $OPENSEAL_API_KEY"
