Get attachment

GET/api/v1/envelopes/{id}/attachments/{sha256}

A signer's attachment, recorded as attachment.downloaded

The file an attachment field's value names, checked against its hash, served as an attachment of the type its leading bytes show (PDF, PNG or JPEG). Recorded in the chain as attachment.downloaded with the field and the hash. Any other hash is 404.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

Path parameters

  • idstringRequired

    Object id (UUIDv7)

  • sha256stringRequired

    The attachment's SHA-256, 64 lower-case hex digits (an attachment field's value)

    matches ^[0-9a-f]{64}$

Returns

200 The file with application/pdf.

GET/api/v1/envelopes/{id}/attachments/{sha256}

curl https://sign.example.com/api/v1/envelopes/01934c50-3ca6-7776-81e5-c4aaecfe9962/attachments/9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08 \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \

Detect fields

POST/api/v1/envelopes/{id}/documents/{doc}/detect-fields

Suggested fields from the document's lines, boxes, labels and form fields

Nothing is changed or recorded. Each suggestion is in the field endpoints' geometry (displayed page space, points, origin top-left); add one by posting it to /fields with a recipient_id. At most 500, ordered by page, top, left; truncated says a bound was reached.
