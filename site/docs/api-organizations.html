Get organization

GET/api/v1/organizations/me

The caller's organization and their role in it

Organization metadata only; no role confers access to agreements. The caller's organization is the session's workspace's; the role is read from organization_admins on every request (no role, or an action it does not hold: 403 CS-AUTH-0006; a non-session credential: 403 CS-AUTH-0006). Another organization's ids answer 404 CS-API-0002.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionorg.read (organization level) · no OAuth scope covers it: it comes from the member's role

Returns

200 with a Organization object.

Update organization

PATCH/api/v1/organizations/me

Rename the organization or replace its policy (org.settings.update), logged as organization.renamed and organization.policy_changed

The policy is the whole document; an invalid key or value is 422 CS-API-0001 at /policy/<key>. Loosening, unlocking or removing a security key is an owner's alone (403 CS-ORG-0013, SEC-O11); tightening is any holder's. Workspace rows are never rewritten: each workspace's effective policy is recomputed per request.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionorg.settings.update (organization level) · no OAuth scope covers it: it comes from the member's role

Request body

Content type application/json · required

  • namestring

    at least 1 characters · at most 255 characters

  • policyOrganizationPolicy

    {key: {value, locked}} for the keys of docs/23 §3 (login.mfa_required, session.max_age, recipient.allowed_auth_methods, sending.min_seal_profile, locale.date_format, reminders.default, ...). locked defaults to true for login.sso_required and login.allowed_methods, false otherwise. Security and evidence keys are tighten-only in a workspace.

Returns

200 with a Organization object.

Join organization workspace

POST/api/v1/organizations/me/workspaces/{id}/join

Become a member of a workspace (org.workspaces.join, owners and admins only)

The only way an organization role reaches agreements: one transaction writes the membership, member.added (via: organization) in the workspace's log and org.workspace_joined in the organization's. A delegated admin gets 403 CS-AUTH-0006; an archived workspace 409 CS-ORG-0010.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionorg.workspaces.join (organization level) · no OAuth scope covers it: it comes from the member's role

Path parameters

  • idstringRequired

    Workspace id (UUIDv7)

Request body

Content type application/json · required

  • profilestringRequired

    admin, sender, viewer, or a permission profile id of that workspace

Returns

201 with a OrgWorkspaceMembership object.

Remove organization admin

DELETE/api/v1/organizations/me/admins/{user}

Remove an administrator (owners only), logged as organization.admin_removed

An owner may resign; the last enabled owner may not (409 CS-ORG-0008).

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

List organization admin events

GET/api/v1/organizations/me/audit

The organization's admin audit log (org.audit.read), oldest first, verified as read

As GET /admin-events, over the organization's chain: workspace creation and archiving, joins, administrator changes, renames, and the platform's operator.* copies.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionorg.audit.read (organization level) · no OAuth scope covers it: it comes from the member's role

Query parameters

    The seq after which to start

    minimum 0

  • limitinteger

    minimum 1 · maximum 1000 · Default 100

  • formatstring

    One of json, csv · Default json

  • verifystring

    One of page, full · Default page
