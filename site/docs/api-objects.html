    Merged; null removes a key. workflow_policy must be a valid policy. stamp_envelope_id is a boolean: whether a new envelope whose request does not say stamps its id on every page. mfa_policy is administrators (the default, also when unset), everyone or optional: who must sign in with a second factor; requiring one is 409 CS-API-0009 while the server has no OPENSEAL_MFA_KEY. AnchorProof

An envelope's anchor proof (openseal.anchor-proof v1, docs/32 §5), canonical JSON (RFC 8785): the chain head (head, the hash of event seq) is leaf leaf_index of the anchor's Merkle tree, by the audit path; the anchor's RFC 3161 token is over its statement. Check it offline with openseal anchor verify or the Verify page, against the TSA's root and, with the audit trail, against the chain.

  • formatstringRequired

    Always openseal.anchor-proof

  • vintegerRequired

    Always 1

  • envelope_idstringRequired
  • seqintegerRequired

    The sequence number of the anchored event

    minimum 0

  • headstringRequired

    The anchored event's hash, sha256: and 64 hex digits

  • leaf_indexintegerRequired

    minimum 0

  • patharray of stringRequired

    The audit path from the leaf up (RFC 9162 §2.1.3)

  • anchorobjectRequired
    Child attributes of anchor
    • formatstringRequired

      Always openseal.anchor

    • vintegerRequired

      Always 1

    • idstringRequired
    • periodstringRequired

      The UTC day whose changed heads the tree covers

      date

    • tree_sizeintegerRequired

      minimum 1

    • rootstringRequired
    • statementstringRequired

      SHA-256 of openseal.anchor.v1, 0x00, the size and the root: what the token is over

    • tsa_timestringRequired

      The token's genTime as the server read it (informative; a verifier reads the token)

      RFC 3339 time

    • timestamp_tokenstringRequired

      The DER TimeStampToken in lower-case hex
