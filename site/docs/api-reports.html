Reporting

Reports

The envelope, recipient and usage reports of a workspace over a window, as JSON or CSV.

Endpoints
  • GET/api/v1/reports/{kind}

Get report

GET/api/v1/reports/{kind}

A workspace report over the envelopes created in a window

DocuSign's envelope, recipient and usage reports. Envelopes created in [from, to) (any time by default), of sender when given, newest first, at most limit; truncated (or the x-truncated header on CSV) says the limit was reached. Envelopes in the Deleted view are left out. format=csv answers text/csv (RFC 4180, CRLF); a cell a spreadsheet would read as a formula starts with '.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionreports.read · OAuth scope admin:account

Path parameters

  • kindstringRequired

    envelopes (one row per envelope), recipients (one row per recipient) or usage (one row per sender); another is 404

    One of envelopes, recipients, usage

Query parameters

  • fromstring

    RFC 3339 time

  • tostring

    RFC 3339 time

  • senderstring

    A user id, or me

  • formatstring

    One of json, csv · Default json

  • limitinteger

    minimum 1 · maximum 10000 · Default 10000

Returns

200 with application/json.

GET/api/v1/reports/{kind}

curl

curl https://sign.example.com/api/v1/reports/0193845e-9183-7131-89e8-9c4d656bdb80?limit=20 \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.getReport({
  kind: "0193845e-9183-7131-89e8-9c4d656bdb80",
  limit: 20,
});

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
data = client.get_report(
    kind="0193845e-9183-7131-89e8-9c4d656bdb80",
    limit=20,
)
