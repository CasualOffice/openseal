Integrations

API clients

Personal API keys, OAuth apps and JWT integrations of a workspace. A key or secret is shown once, when it is created.

Endpoints
  • GET/api/v1/api-clients
  • POST/api/v1/api-clients
  • GET/api/v1/api-clients/{id}
  • DELETE/api/v1/api-clients/{id}

List API clients

GET/api/v1/api-clients

API keys and OAuth clients

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionapi_clients.manage · OAuth scope admin:account

Returns

200 with a ApiClientList object.

GET/api/v1/api-clients

curl

curl https://sign.example.com/api/v1/api-clients \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.listApiClients();

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
data = client.list_api_clients()

Create API client

POST/api/v1/api-clients

New API key or OAuth client; the secret is shown once

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionapi_clients.manage · OAuth scope admin:account

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • namestringRequired

    at most 255 characters

  • kindstringRequired

    One of api_key, oauth_app, jwt_integration

  • scopesarray of stringRequired
  • owner_user_idstring
  • expires_in_daysinteger

    minimum 1 · maximum 3650

  • redirect_urisarray of string

    OAuth apps and JWT integrations: where authorization codes go after consent; https://, or http:// to localhost, 127.0.0.1 or [::1]; no fragment (422 at /redirect_uris/{i})

    at most 10 items

  • public_keystring

    JWT integrations only, and required: a -----BEGIN PUBLIC KEY----- PEM, EC P-256 (ES256) or RSA (RS256); a private key is refused (422 at /public_key)

    at most 8192 characters

Returns

201 with a ApiClientCreated object.

POST/api/v1/api-clients

curl

curl -X POST https://sign.example.com/api/v1/api-clients \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H 'Idempotency-Key: order-1042' \
  -H "Content-Type: application/json" \
  -d '{
  "name": "CRM sync",
  "kind": "api_key",
  "scopes": [
    "envelopes:read",
    "envelopes:write"
  ],
  "expires_in_days": 90
}'

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const result = await os.createApiClient({
  idempotencyKey: "order-1042",
  body: {
    "name": "CRM sync",
    "kind": "api_key",
    "scopes": [
      "envelopes:read",
      "envelopes:write"
    ],
    "expires_in_days": 90
  },
});
