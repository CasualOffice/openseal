Core resources

Fields

What each recipient fills: signatures, initials, dates, text, check boxes and the other field types, placed by page coordinates or by anchor text. Values are read back as form data.

Endpoints
  • GET/api/v1/envelopes/{id}/fields
  • POST/api/v1/envelopes/{id}/fields
  • GET/api/v1/envelopes/{id}/fields/{f}
  • PATCH/api/v1/envelopes/{id}/fields/{f}
  • DELETE/api/v1/envelopes/{id}/fields/{f}
  • GET/api/v1/envelopes/{id}/form-data

List fields

GET/api/v1/envelopes/{id}/fields

Fields, optionally of one recipient or document

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Query parameters

  • recipient_idstring
  • document_idstring

Returns

200 with a FieldList object.

Add fields

POST/api/v1/envelopes/{id}/fields

Add one field, or {items: [...]}

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.write · OAuth scope envelopes:write

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

FieldCreate

Returns

201 with a FieldList object.
