List templates

GET/api/v1/templates

Templates the caller may use, by view; with deleted=true the Deleted view

The live templates the caller may use, by name: their own, those shared with them (directly, through a group, or with the whole account) and, for an administrator, every one. view narrows the list: owned, shared (Shared with me: another member's templates a share reaches the caller by) or favourites (the caller's starred ones). With deleted=true, the deleted templates the caller owns (every one for an administrator), kept whole and restorable, most recently deleted first. Any other value is 422.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissiontemplates.read · OAuth scope templates:read

Query parameters

  • deletedstring

    true: the Deleted view.

    One of true, false

  • viewstring

    all (default), owned, shared (Shared with me) or favourites.

    One of all, owned, shared, favourites

  • folderstring

    One of the caller's template folders (another member's matches nothing), or none: in none of the caller's folders. Each item carries the caller's folder_id (or null).

Returns

200 with a TemplateList object.

Replace template shares

PUT/api/v1/templates/{id}/shares

Replace a template's shares with members, groups or the whole account

The whole set of shares. A user is a member of this account, named by id or email; a group is one of its groups. Sharing with the owner, or naming one target twice, is 422. A share lets its members use the template, and edit it with can_edit; deleting, restoring and sharing stay with the owner and administrators. Anyone without access is answered 404, too little access 403.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissiontemplates.write · OAuth scope templates:write

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Request body

Content type application/json · required

  • itemsarray of objectRequired

    at most 500 items

    Child attributes of items
    • user_idstring
    • emailstring

      at least 3 characters · at most 320 characters

    • group_idstring
    • accountboolean

      One of true

    • can_editboolean

      Default false

Returns

200 with a TemplateShares object.

Limits

  • Template shares (PUT /templates/{id}/shares, UXW-06): shares per template; a member's email: 0–500; 3–320 bytes after trimming
