Recipients

The people (and roles) an envelope routes to: signers, approvers, viewers, copies and the other recipient types, each with a routing order and the authentication they must pass.

Endpoints
  • GET/api/v1/envelopes/{id}/recipients
  • POST/api/v1/envelopes/{id}/recipients
  • GET/api/v1/envelopes/{id}/recipients/{r}
  • PATCH/api/v1/envelopes/{id}/recipients/{r}
  • DELETE/api/v1/envelopes/{id}/recipients/{r}
  • POST/api/v1/envelopes/{id}/recipients/{r}/host

Update recipient

PATCH/api/v1/envelopes/{id}/recipients/{r}

Change a recipient (If-Match required)

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.write · OAuth scope envelopes:write

Path parameters

  • idstringRequired

    Object id (UUIDv7)

  • rstringRequired

    Recipient id

Headers

  • If-MatchstringRequired

    The envelope's ETag as read ("v<version>"); a stale one is 412 CS-WF-0002, none is 428 CS-API-0008.

Request body

Content type application/json · required

  • namestring
  • emailstring
  • routing_orderinteger
  • typestring

    A new type, on a draft only; a correction keeps the type and is refused 409.

    One of signer, in_person_signer, approver, viewer, cc, editor, intermediary, agent, witness, seal, notary

  • autharray of string
  • access_codestring

    A new access code, stored only as Argon2id. Needed when auth gains access_code; refused when the resulting auth lacks it. Removing access_code from auth deletes the stored code. Draft or correcting envelopes only.

    at most 255 characters

  • excluded_documentsarray of string

    Document ids hidden from this recipient; [] shows every document

  • route_delay_hoursinteger

    Delayed routing: hours to wait once their turn comes; 0 invites at once

    minimum 0 · maximum 65535

Returns

200 with a Recipient object.
