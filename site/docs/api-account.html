Account settings

The workspace's settings: sending, signing, security, branding defaults and document analysis.

Endpoints
  • GET/api/v1/accounts/me
  • PATCH/api/v1/accounts/me
  • GET/api/v1/account/settings/ml
  • PATCH/api/v1/account/settings/ml

Get account

GET/api/v1/accounts/me

The caller's account

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session; any signed-in caller

Returns

200 with a Account object.

GET/api/v1/accounts/me

curl

curl https://sign.example.com/api/v1/accounts/me \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.getAccount();

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
data = client.get_account()

Update account

PATCH/api/v1/accounts/me

Merge into the account's settings

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionsettings.sending · OAuth scope admin:account

Request body

Content type application/json · required

  • settingsobjectRequired

    Merged; null removes a key. workflow_policy must be a valid policy. stamp_envelope_id is a boolean: whether a new envelope whose request does not say stamps its id on every page. mfa_policy is administrators (the default, also when unset), everyone or optional: who must sign in with a second factor; requiring one is 409 CS-API-0009 while the server has no OPENSEAL_MFA_KEY. A setting the organization's policy governs that changes to a locked or looser value is 422 CS-ORG-0002, naming the setting and the key.

Returns

200 with a Object object.

PATCH/api/v1/accounts/me

curl

curl -X PATCH https://sign.example.com/api/v1/accounts/me \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "settings": {}
}'

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const result = await os.patchAccount({
  body: {
    "settings": {}
  },
});

Python

import os

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
result = client.patch_account(
    body={
        "settings": {},
    },
)

Update ML settings

PATCH/api/v1/account/settings/ml

Turn document-analysis features on or off

Turning on a feature the plan lacks, or any feature while the model service is not installed, is 403 CS-ML-0011; turning one off is always allowed.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionsettings.sending · OAuth scope admin:account

Request body

Content type application/json · required

  • ocrboolean
  • template_matchingboolean
  • extractionboolean
  • personal_databoolean
  • personal_data_modelstring or null

    matches ^[A-Za-z0-9._-]{1,64}$

  • ocr_scriptsarray of string

    at most 16 items

  • reread_scanner_textboolean

Returns

200 with a MlSettings object.

PATCH/api/v1/account/settings/ml

curl -X PATCH https://sign.example.com/api/v1/account/settings/ml \
