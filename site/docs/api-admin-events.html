Administration

Admin audit log

The workspace's log of administrative changes, as JSON or CSV.

Endpoints
  • GET/api/v1/admin-events

List admin events

GET/api/v1/admin-events

The workspace's admin audit log, oldest first, verified before it is answered

Every settings, member, profile and workspace change, hash-chained per workspace. Each item carries its seq, hash, prev and the event as its RFC 8785 canonical JSON; hash is SHA-256 of those bytes. Each page is verified as it is read: linked to the event at its cursor, the last page to the stored head, and each at to its bytes, so walking the log by cursor checks every link once. verify=full re-verifies the whole log first. A broken chain is 500 CS-DB-0014. format=csv answers text/csv with columns seq,at,action,hash,prev,event and the next cursor in X-Next-Cursor.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionadmin_audit.read · OAuth scope admin:account

Query parameters

  • cursorinteger

    The seq after which to start

    minimum 0

  • limitinteger

    minimum 1 · maximum 1000 · Default 100

  • formatstring

    One of json, csv · Default json

  • verifystring

    page verifies the page read; full re-verifies the whole log first; another value is 422 CS-API-0001

    One of page, full · Default page

Returns

200 with a AdminEventList object.

GET/api/v1/admin-events

curl

curl https://sign.example.com/api/v1/admin-events?limit=20 \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.listAdminEvents({
  limit: 20,
});

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
data = client.list_admin_events(
    limit=20,
)
