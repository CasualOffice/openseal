The endpoints behind a recipient's signing link (/s/{token}), used by OpenSeal's own signing page. They are documented for completeness and security review; they are not public API and may change without notice. Integrations embed signing with Create signing view instead.

Not public API. These endpoints serve OpenSeal's own signing page and may change in any release. Do not build on them.

AuthThe signing link's token in the path; no API credential. Not public API.

Ceremony OTP send

POST/s/{token}/otp

Send a one-time code

Sends the recipient a 6-digit code for method: by email (email_otp, the default), by SMS (sms_otp) or read aloud in a voice call (voice_otp) to the recipient's phone (slice 5), when the sender required that method. The worker draws the code and stores only its Argon2id hash; it works once, for 10 minutes, and asking again (by any method) replaces it. Limited per link and per address or phone number (3 a minute) and per recipient (30 seconds apart, 5 an hour): CS-API-0003 with Retry-After. CS-API-0014 when the recipient does not require that method; CS-API-0009 once it has passed. Without an SMS and voice provider on the worker such a code is never sent (CS-WRK-0013).

AuthThe signing link's token in the path; no API credential. Not public API.

Path parameters

  • tokenstringRequired

    Ceremony link token (secret)

Request body

Content type application/json

  • methodstring

    One of email_otp, sms_otp, voice_otp

  • locationDeviceLocation

    The browser's Geolocation fix, or a decline (row GEO-01).

Returns

202 Accepted; the code is on its way with a CeremonyView object.

Ceremony name recipients

POST/s/{token}/recipients

Name later recipients (agent, intermediary, editor)

An agent supplies the name and email of recipients later in the routing order who have not been reached yet (the view's later_recipients), then finishes with POST /s/{token}/finish. An intermediary or editor may call it too. Any other recipient type is refused (409); a recipient of the caller's own order or earlier, or one already reached, is refused by the workflow (403). An intermediary or editor may also set phone, auth and an access_code (VS-06A; the code stored as Argon2id, never answered). The change is recorded as envelope.corrected with the recipient as actor.
