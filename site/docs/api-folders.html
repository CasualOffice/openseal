Core resources

Folders

Each member's own folders for envelopes and templates.

Endpoints
  • GET/api/v1/folders
  • POST/api/v1/folders
  • PATCH/api/v1/folders/{id}
  • DELETE/api/v1/folders/{id}
  • POST/api/v1/folders/{id}/envelopes
  • POST/api/v1/folders/{id}/templates

List folders

GET/api/v1/folders

The caller's own envelope (or template) folders, by name, with counts

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

Query parameters

  • kindstring

    envelopes (default) or templates; any other is 422.

    One of envelopes, templates

Returns

200 with application/json.

GET/api/v1/folders

curl

curl https://sign.example.com/api/v1/folders \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.listFolders();

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
data = client.list_folders()

Create folder

POST/api/v1/folders

A new folder of the caller's (at most 500)

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.write · OAuth scope envelopes:write

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • namestringRequired

    Trimmed; unique among the caller's folders of its kind ignoring case (422 exists at /name)

    at least 1 characters · at most 100 characters

  • kindstring

    On create only (422 at /kind on a rename): envelopes (default) or templates

    One of envelopes, templates

Returns

201 with a Folder object.

POST/api/v1/folders

curl

curl -X POST https://sign.example.com/api/v1/folders \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H 'Idempotency-Key: order-1042' \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Q4 contracts",
  "kind": "envelopes"
}'

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const result = await os.createFolder({
  idempotencyKey: "order-1042",
  body: {
    "name": "Q4 contracts",
    "kind": "envelopes"
  },
});

Python

Move envelopes

POST/api/v1/folders/{id}/envelopes

File 1 to 200 envelopes the caller may see in a folder of theirs, or in none, all or nothing

Filing is the caller's own view of their lists: the envelopes, their updated_at and their audit chains are untouched. An envelope the caller may not see is 404 and nothing moves.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.write · OAuth scope envelopes:write

Path parameters

  • idstringRequired

    One of the caller's folders, or none to file the envelopes in no folder

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • envelope_idsarray of stringRequired

    at least 1 items · at most 200 items

Returns

200 with application/json.

Move templates

POST/api/v1/folders/{id}/templates

File 1 to 200 templates the caller may use in a template folder of theirs, or in none, all or nothing

Filing is the caller's own view of their template list: the templates and their versions are untouched. A template the caller may not use, or another account's, is 404 and nothing moves.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissiontemplates.read · OAuth scope templates:read

Path parameters

  • idstringRequired

    One of the caller's template folders (an envelope folder is 404), or none to file the templates in no folder

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • template_idsarray of stringRequired

    at least 1 items · at most 200 items

Returns

200 with application/json.
