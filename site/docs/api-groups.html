Administration

Groups

Groups of members, used for template sharing and administrative scope.

Endpoints
  • GET/api/v1/groups
  • POST/api/v1/groups
  • GET/api/v1/groups/{id}
  • PATCH/api/v1/groups/{id}
  • DELETE/api/v1/groups/{id}
  • PUT/api/v1/groups/{id}/members

List groups

GET/api/v1/groups

The account's groups with member counts, for sharing templates

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissiontemplates.read · OAuth scope templates:read

Returns

200 with a GroupList object.

GET/api/v1/groups

curl

curl https://sign.example.com/api/v1/groups \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.listGroups();

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
data = client.list_groups()

Create group

POST/api/v1/groups

Make a group of members; a name the account uses is 422 exists at /name

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissiongroups.manage · OAuth scope admin:users

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • namestringRequired

    at least 1 characters · at most 255 characters

Returns

201 Created with a Group object.

POST/api/v1/groups

curl

curl -X POST https://sign.example.com/api/v1/groups \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H 'Idempotency-Key: order-1042' \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Sales"
}'

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const result = await os.createGroup({
  idempotencyKey: "order-1042",
  body: {
    "name": "Sales"
  },
});

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
result = client.create_group(
    idempotency_key="order-1042",
    body={
        "name": "Sales",
    },
)

Set group members

PUT/api/v1/groups/{id}/members

Make the group's members exactly these members of the account

Each id must be a member of this account (422 at /user_ids/{i} otherwise); a repeated id counts once. Each member added or removed is its own admin event.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissiongroups.manage · OAuth scope admin:users

Path parameters

  • idstringRequired

    A group of this account (another account's is 404)

Request body

Content type application/json · required

  • user_idsarray of stringRequired

Returns

200 with a Group object.

PUT/api/v1/groups/{id}/members

curl

curl -X PUT https://sign.example.com/api/v1/groups/0193ad93-6fcb-7ed6-831f-a67e05c3ea03/members \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "user_ids": [
    "019304f8-996d-7a76-83b7-a969b1028ee3"

}'
