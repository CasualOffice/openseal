Administration

Retention and legal hold

Retention rules that purge ended envelopes, their preview, legal holds and purging one envelope.

Endpoints
  • GET/api/v1/retention
  • PUT/api/v1/retention
  • GET/api/v1/retention/preview
  • PUT/api/v1/envelopes/{id}/legal-hold
  • DELETE/api/v1/envelopes/{id}/legal-hold
  • POST/api/v1/envelopes/{id}/purge

Get retention

GET/api/v1/retention

The account's retention rules

{keep_days: {draft, ended, completed, sessions}, max_keep_days}: days a record of each class is kept after its last change (completion, for completed envelopes), or null to keep it for ever (the default).

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionretention.manage · OAuth scope admin:account

Returns

200 with a Object object.

curl

curl https://sign.example.com/api/v1/retention \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

Set retention

PUT/api/v1/retention

Set or remove retention rules

{keep_days: {class: days | null}}, days 1 to 36500; classes left out are unchanged. After a recent re-authentication. Each change is the admin event retention.rule_set. The daily retention job then purges what a rule expires, never an envelope under legal hold or in flight.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionretention.manage · OAuth scope admin:account

Request body

Content type application/json · required

Object

Returns

200 with a Object object.

Purge envelope

POST/api/v1/envelopes/{id}/purge

Purge an envelope now, at the controller's request

For an envelope that completed, ended or was never sent, after a recent re-authentication: appends envelope.purged with the policy request and queues the purge of its documents and personal data; its audit chain and a tombstone stay. 409 CS-API-0019 under legal hold; 409 CS-WF-0001 in flight or already purged. How a signer's erasure request is carried out by the account that holds their envelope.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionretention.manage · OAuth scope admin:account

Path parameters

  • idstringRequired

    Object id (UUIDv7)

    uuid

Returns

202 Purged; the records follow by job with a Object object.
