OAuth

The OAuth 2.1 authorization server: the token endpoint (client credentials, authorization code with PKCE, refresh token, JWT bearer grant), consent, and discovery metadata and keys.

Endpoints
  • POST/api/v1/oauth/token
  • GET/.well-known/oauth-authorization-server
  • GET/api/v1/oauth/authorize
  • POST/api/v1/oauth/authorize
  • GET/api/v1/oauth/authorize/request
  • GET/api/v1/oauth/consents
  • DELETE/api/v1/oauth/consents/{id}
  • GET/.well-known/jwks.json

Token endpoint

POST/api/v1/oauth/token

OAuth 2.1 token endpoint: client credentials, authorization code with PKCE, refresh token, JWT bearer grant

RFC 6749 §5.2 errors, with the CS-* code as error_description: invalid_client (CS-AUTH-0007), invalid_grant (CS-AUTH-0014: a code or refresh token unknown, spent, expired or not this client's, a wrong PKCE verifier or redirect URI, an assertion with a bad signature, audience or lifetime; CS-AUTH-0005: the member has not consented to the JWT integration), invalid_scope (CS-AUTH-0006), unsupported_grant_type.

AuthNone (public)

Request body

Content type application/json · required

  • grant_typestringRequired

    One of client_credentials, authorization_code, refresh_token, urn:ietf:params:oauth:grant-type:jwt-bearer

  • client_idstring
  • client_secretstring
  • scopestring
  • codestring

    authorization_code

  • redirect_uristring

    authorization_code: the URI the code was issued to

  • code_verifierstring

    authorization_code: the PKCE verifier

    at least 43 characters · at most 128 characters

  • refresh_tokenstring

    refresh_token: rotated on every use; one spent twice revokes its family

  • assertionstring

    The JWT bearer grant's signed assertion

Returns

200 with a TokenResponse object.

POST/api/v1/oauth/token

curl

curl -X POST https://sign.example.com/api/v1/oauth/token \
  -u "$CLIENT_ID:$CLIENT_SECRET" \
  -d grant_type=client_credentials \
  -d scope="envelopes:read envelopes:write"

Authorization endpoint

GET/api/v1/oauth/authorize

Authorization endpoint: hands the request to the web app's consent screen

303 to /app.html#/authorize?<the same query>; the screen signs the member in if needed, reads the checked request and posts the answer. Nothing is checked or recorded here.

AuthNone (public)

Returns

303 To the consent screen with no body.

Answer a consent request

POST/api/v1/oauth/authorize

The member's answer to an authorization request

A staff session only (422 at /credential otherwise). allow records the member's consent (widening a live one) and answers the redirect with a one-time code (ten minutes), state and iss; deny answers it with error=access_denied. Refusals are problems at the request's member (/client_id, /redirect_uri, /response_type, /code_challenge, /scope, /state, /decision), never a redirect to an unregistered URI.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session; any signed-in caller

Request body

Content type application/json · required

  • response_typestringRequired

    Always code

  • client_idstringRequired
  • redirect_uristringRequired

    One of the client's registered redirect URIs, exactly

  • scopestringRequired

    Space-separated; each within the client's scopes and the member's own

  • statestring

    at most 512 characters

  • code_challengestringRequired

    at least 43 characters · at most 128 characters

  • code_challenge_methodstringRequired

    Always S256

  • decisionstring

    POST only

    One of allow, deny

Returns

200 with application/json.

Check an authorization request

GET/api/v1/oauth/authorize/request

An authorization request, checked, for the consent screen to show

The query of GET /oauth/authorize, checked against the client and the signed-in member as POST /oauth/authorize checks it; answers the client's name and the scopes asked.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session; any signed-in caller

Query parameters

  • response_typestringRequired
  • client_idstringRequired
  • redirect_uristringRequired
  • scopestringRequired
  • statestring
  • code_challengestringRequired
  • code_challenge_methodstringRequired

Returns

200 with application/json.
