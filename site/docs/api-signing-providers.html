Administration

Signing providers

The remote signing providers the operator offers the workspace (RSP-01): which are enabled, and their options.

Endpoints
  • GET/api/v1/signing-providers
  • GET/api/v1/signing-providers/{id}
  • PUT/api/v1/signing-providers/{id}

List signing providers

GET/api/v1/signing-providers

Signing providers the operator offers this account

The providers of the operator's catalogue offered to this account, each with whether the account enabled it. A sender may name an enabled one as a signer's signature.provider_id.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.write · OAuth scope envelopes:write

Returns

200 with a SigningProviderList object.

GET/api/v1/signing-providers

curl

curl https://sign.example.com/api/v1/signing-providers \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.listSigningProviders();

Get signing provider

GET/api/v1/signing-providers/{id}

A provider's settings for this account (404 when not offered)

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionsettings.signing · OAuth scope admin:account

Path parameters

  • idstringRequired

    The catalogue's provider id

Returns

200 with a SigningProviderSettings object.

Put signing provider

PUT/api/v1/signing-providers/{id}

Enable or disable a provider and set its options

Each change is a workspace.signing_provider_changed admin event; an own client secret is recorded only as rotated or removed.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionsettings.signing · OAuth scope admin:account

Path parameters

  • idstringRequired

    The catalogue's provider id

Request body

Content type application/json · required

  • enabledbooleanRequired
  • required_qualifiersarray of string

    at most 8 items

  • refuse_name_mismatchboolean
  • session_minutesinteger

    minimum 5 · maximum 60

  • client_secretstring or null

    The account's own OAuth client secret for this provider: stored sealed with AES-256-GCM, never returned; null removes it

    at most 2048 characters

Returns

200 with a SigningProviderSettings object.

PUT/api/v1/signing-providers/{id}

curl

curl -X PUT https://sign.example.com/api/v1/signing-providers/01934fc1-4a1e-7146-8484-a6a729ab7300 \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "enabled": false,
  "required_qualifiers": [
    "123456"
  ],
  "refuse_name_mismatch": false,
  "session_minutes": 5,
  "client_secret": "example-client-secret-shown-once"
}'

TypeScript

import { OpenSeal } from "@openseal/sdk";
