Core resources

Contacts

People the caller has sent to, for recipient suggestions.

Endpoints
  • GET/api/v1/contacts

List contacts

GET/api/v1/contacts

Past recipients for autocomplete: one per email address, most recently used first

From the envelopes the caller may see (their own without view_all), never another account's. q matches the name or email, ignoring case; limit is 1 to 50 (default 10).

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

Query parameters

  • qstring

    Text the name or email contains (ignoring case); at most 200 characters, no control characters.

    at most 200 characters

  • limitinteger

    minimum 1 · maximum 50 · Default 10

Returns

200 with a ContactList object.

Limits

  • Contacts search (GET /contacts; WEB-06): q 200 characters, limit 1–50
GET/api/v1/contacts

curl

curl https://sign.example.com/api/v1/contacts?limit=20 \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

TypeScript

import { OpenSeal } from "@openseal/sdk";

const os = new OpenSeal({ baseUrl: "https://sign.example.com", apiKey: process.env.OPENSEAL_API_KEY });
const data = await os.listContacts({
  limit: 20,
});

Python

import os
from openseal import OpenSeal

client = OpenSeal("https://sign.example.com", api_key=os.environ["OPENSEAL_API_KEY"])
data = client.list_contacts(
    limit=20,
)
