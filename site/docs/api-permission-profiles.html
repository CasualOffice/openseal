Permission profiles

What members may do: the built-in profiles and custom ones, as actions of the catalogue.

Endpoints
  • GET/api/v1/permission-profiles
  • POST/api/v1/permission-profiles
  • GET/api/v1/permission-profiles/{id}
  • PATCH/api/v1/permission-profiles/{id}
  • DELETE/api/v1/permission-profiles/{id}

List permission profiles

GET/api/v1/permission-profiles

The built-in profiles, then the custom ones, with what each grants and how many members hold it

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionusers.read · OAuth scope admin:users

Returns

200 with a PermissionProfileList object.

GET/api/v1/permission-profiles

curl

curl https://sign.example.com/api/v1/permission-profiles \
  -H "Authorization: Bearer $OPENSEAL_API_KEY"

Create permission profile

POST/api/v1/permission-profiles

Make a custom permission profile

Its permissions are scopes of docs/40 §2, view_all_envelopes and workspace actions; none may go beyond the caller's own, nor its group scope beyond the caller's, nor a sensitive action with a group scope (403 CS-ORG-0005). A name the account uses is 422 exists at /name.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionprofiles.manage · OAuth scope admin:users

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • namestringRequired

    at least 1 characters · at most 255 characters

  • permissionsarray of stringRequired
  • admin_scope_group_idsarray of string or null

    Groups of this account its holders administer (a delegated workspace admin); absent or null for the whole workspace. Never with a sensitive action.

    at least 1 items

Returns

201 Created with a PermissionProfile object.

POST/api/v1/permission-profiles

curl

curl -X POST https://sign.example.com/api/v1/permission-profiles \
  -H "Authorization: Bearer $OPENSEAL_API_KEY" \
  -H 'Idempotency-Key: order-1042' \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Sender",
  "permissions": [
    "envelopes:read"
  ],
  "admin_scope_group_ids": [
    "0193b015-9b5b-7e70-82f3-185b7cfa6739"
  ]
}'

Update permission profile

PATCH/api/v1/permission-profiles/{id}

Change a custom profile; its members hold the new permissions from their next request

A built-in profile is 409 CS-WF-0001. The profile as it was and as it becomes must both be within the caller's rights and scope, and never the caller's own profile (403 CS-ORG-0005). Giving sending to more members is checked against the plan's seats (CS-PLAN-0003).

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionprofiles.manage · OAuth scope admin:users

Path parameters

  • idstringRequired

    A permission profile of this account (another account's is 404)

Request body

Content type application/json · required

  • namestring

    at least 1 characters · at most 255 characters

  • permissionsarray of string
  • admin_scope_group_idsarray of string or null

    Absent unchanged; null the whole workspace; a list those groups

    at least 1 items

Returns

200 with a PermissionProfile object.
