Audit and evidence

The envelope's hash-chained audit trail, the certificate of completion, and the anchor proof that ties the trail's head to a time-stamped daily anchor. Each can be checked offline.

Endpoints
  • GET/api/v1/envelopes/{id}/audit
  • GET/api/v1/envelopes/{id}/anchor-proof
  • GET/api/v1/envelopes/{id}/certificate
  • GET/api/v1/envelopes/{id}/evidence-package

Get audit trail

GET/api/v1/envelopes/{id}/audit

Hash-chained audit events, re-verified on read

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionaudit.read · OAuth scope audit:read

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Returns

200 with a AuditEvents object.

Get anchor proof

GET/api/v1/envelopes/{id}/anchor-proof

The anchor proof of the envelope's latest anchored chain head

The proof file (openseal.anchor-proof v1, canonical JSON) of the envelope's latest audit chain head that the daily anchor job anchored: the head, its leaf index and audit path, and that day's anchor with its RFC 3161 token. Check it offline with openseal anchor verify or the Verify page. 404 CS-API-0017 while no head of the envelope is anchored yet (the job runs after each UTC day closes). A read of evidence (security log); not recorded in the chain.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Returns

200 The proof file, as an attachment named anchor-proof.json with a AnchorProof object.

Get certificate

GET/api/v1/envelopes/{id}/certificate

Certificate of completion PDF (made by the seal job), or a declined, voided or expired envelope's envelope certificate

A completed envelope's certificate of completion. A declined, voided or expired envelope's envelope certificate says how it ended and never claims completion; the worker makes and seals it when the envelope ends. 409 CS-API-0009 before either exists (an ended envelope without one asks the worker for it then).

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Returns

200 PDF with application/pdf.

Get evidence package

GET/api/v1/envelopes/{id}/evidence-package

One ZIP with everything that proves the agreement, recorded as envelope.exported

For an envelope that is over (completed, or declined, voided or expired): a ZIP of stored entries holding manifest.json, each document as sealed (as it ended, with the "not signed" banner, for one that ended without completing) under documents/, certificate.pdf (the certificate of completion, or the envelope certificate of UXW-30) and audit-trail.json (the events as GET …/audit gives them, with chain_head). The manifest (format: openseal.evidence-package, version: 1) names every other entry with its sha256 and size, and the chain head. The export is recorded first as envelope.exported, so the trail in the package ends with it. In flight, a draft, or purged is 409 CS-WF-0001; a certificate not made yet 409 CS-API-0009 (an ended envelope asks the worker for it, as GET …/certificate does).

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionenvelopes.read · OAuth scope envelopes:read

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Returns

200 ZIP with application/zip.
