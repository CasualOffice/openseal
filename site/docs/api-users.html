Update my profile

PATCH/api/v1/users/me

Change one's own profile

{name?, notifications?, signature?, initials?, password?, current_password?}. A mark is {image_base64} (PNG or JPEG, at most 5 MiB) or null to remove it. The name and password are the user's in every account and change only through their own session (422 with another credential). A new password needs the current one (401 CS-AUTH-0007 when wrong) and ends every other session of the user in every account; this session stays.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session; any signed-in caller

Request body

Content type application/json · required

Object

Returns

200 with a Object object.

Limits

  • Saved signature or initials (PATCH /users/me, UXW-37): a PNG or JPEG of 1 byte to 5 MiB (base64 text at most 6,990,508 characters); a name 1–255 characters after trimming

Erase my account

DELETE/api/v1/users/me

Erase one's own identity in this workspace

After a recent re-authentication (403 CS-AUTH-0013 otherwise), from a session of the person (422 with another credential): name and email replaced by a marker, login binding, password and second factor removed, sessions here ended, saved signature, notices, invitations and password resets deleted, owned API clients revoked; recorded as the admin event member.erased. Audit events, admin logs, tombstones and sealed documents are never altered. 403 CS-API-0015 for a member of another workspace too; 409 CS-API-0018 for the workspace's last administrator or an organization administrator.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session; any signed-in caller

Returns

204 Erased with no body.

Export my data

Export one's own data in this workspace

One JSON document {format: "openseal.personal-data-export", v: 1, exported_at, workspace, user, login_kind, profile, sessions, api_clients, envelopes, templates, kept}. Each envelope the caller sent lists the routes serving its documents, certificate and audit trail, each authorized and logged per object. Nothing of another workspace or member. At most 3 a minute per user (429); logged as a data.document_read security event.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session; any signed-in caller

Update user

PATCH/api/v1/users/{id}

Rename a member, set their password, change their profile, disable or enable them

The name and password belong to the user in every account. An administrator, or any API key (the user's own included), changes them only for a user whose one membership is this account; for a user who also belongs to another account it is 403 CS-API-0015 and nothing in the request is applied. The user changes their own name and password through their own session; a new password ends their sessions in every account. Profile fields and disabling apply to this account's membership only.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionusers.update · OAuth scope admin:users

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Request body

Content type application/json · required

  • namestring

    at most 255 characters

  • passwordstring

    Not on the bundled list of breached passwords, case ignored (422 common_password at /password, ASVS-02); setting it emails the user a notice

    at least 12 characters · at most 256 characters

  • profilestring

    admin, sender, viewer, or a permission profile id; not your own

  • disabledboolean

    Disable (ending their sessions and open invitations) or enable the member in this account only; not yourself

Returns

200 with a User object.

Reset member second factor

POST/api/v1/users/{id}/second-factor/reset

Reset the second factors of a member who lost them (ASVS-32, ASVS 2.5.7)

For an administrator of the workspace (or of its organization) signed in with a staff session that re-authenticated within five minutes (403 CS-AUTH-0013); never an API key or token, never oneself (422). identity_verified_by records how the person's identity was proved out of band. The member must belong to this workspace alone (403 CS-API-0015). Their TOTP authenticator, passkeys and recovery codes are removed, their sessions end, and their next sign-in must enrol a new factor before anything else, whatever the policy. Recorded in the administrative log (member.factors_reset) and the security log (auth.mfa_remove); the member is told by email.

AuthAPI key or OAuth access token (Authorization: Bearer), or a staff session

Permissionusers.update · OAuth scope admin:users

Path parameters

  • idstringRequired

    Object id (UUIDv7)

Headers

  • Idempotency-Keystring

    Up to 255 printable ASCII characters; a replay within 24 hours returns the first response.

    at most 255 characters

Request body

Content type application/json · required

  • identity_verified_bystringRequired

    One of in_person, video_call, phone_callback, manager_confirmation, identity_document

Returns

200 Reset with application/json.
